How it works

Time stops. The camera doesn't.

The take is never retimed outside the ramp, so speech before and after the freeze stays in sync with its own audio. Every arc starts and ends on the real frame, so both cuts land on the same image.

Pick the moment

OpenCV scores every frame by motion x sharpness, so the freeze lands on the peak without blur. MediaPipe rules out closed eyes: nobody wants to orbit a blink. Scrub to pick your own.

free · CPU

8 views

Qwen-Image-Edit 2511 with the Multiple-Angles LoRA, prompted in its trained <sks> format. Each still is checked; a sideways or upside-down view is rejected.

1 job · ~$0.045

The orbit

LTX-2.5 22B: your real frame sits in the latent, every view becomes an LTXVAddGuide keyframe, and the prompt holds time still. Up to 704x1280, audio in the same pass. LTX-2.3 is still one switch away.

1 job · ~$0.055

Splice

ffmpeg ramps into the freeze, plays the orbit, rewinds home and resumes on the very frame it froze on.

The app

Drop a clip, pick a move, Generate

A small local web app runs the whole pipeline. It shows where the motion peaks, lets you scrub to the exact frame, and prices the run before it spends anything.

Your key stays yours

The Comfy Cloud key lives in your browser and is forwarded per request through your local server. Never written to disk or logged.

Re-roll cheaply

Keep the 8 views and re-roll only the orbit (1 job), or change the ramp and slow-mo and re-render for free.

Take the graphs with you

ComfyUI workflows downloads the exact API graphs submitted for your result, ready to open in ComfyUI.

Run it

Five commands to your first freeze

Python 3.10+ and ffmpeg on PATH. No local GPU needed: generation runs on Comfy Cloud with your own key.

> git clone https://github.com/apsolut/bullet-time-comfyui
> cd bullet-time-comfyui
> python -m venv .venv && .venv\Scripts\activate
> pip install -e .
> bullettime serve           # http://127.0.0.1:8790
$ git clone https://github.com/apsolut/bullet-time-comfyui
$ cd bullet-time-comfyui
$ python -m venv .venv && . .venv/bin/activate
$ pip install -e .
$ bullettime serve           # http://127.0.0.1:8790

Prefer the command line?

# set COMFY_API_KEY first (never commit it)
# free: where would it freeze?
$ bullettime analyze take.mp4
# plan + cost, then the real run
$ bullettime -P work run take.mp4 --arc sweep --dry-run
$ bullettime -P work run take.mp4 --arc sweep --out bt.mp4
# re-roll only the orbit (same views), or re-render for free
$ bullettime -P work orbit --arc orbit-left
$ bullettime -P work render --ramp 0.8 --slow 4
# the exact graph, for ComfyUI
$ bullettime workflow --arc sweep > sweep_api.json

In the web app

  1. Paste your Comfy Cloud API key and press Check.
  2. Drop a clip, up to 30 s, one person.
  3. Check the moment it picked, or scrub and press Freeze at current frame.
  4. Pick an arc and press Generate bullet time. About two minutes later you have an MP4.

Film for it

  • A clear peak: a jump, a hair flip, a throw, a splash.
  • Good light, so the frozen frame is sharp.
  • Keep the person in frame with some room around them.
v0.2 Studio

Built to run as a service, not a toy

Everything a team needs, still all open weights on Comfy Cloud. See Studio use in the README.

Fix one view

A rejected view (sideways, wrong orientation, closed eyes) is re-rolled on its own in a pruned single-view graph, automatically before every orbit.

~$0.025 per view

Variants

Three orbits with different seeds submitted at once. Pick the best one in the web app.

3 x $0.055

Colour match + upscale

KJNodes ColorMatch locks the orbit's grade to your real frame. SeedVR2 3B takes it to a 1080 short side, with its audio.

free · ~$0.12

Studio export

ProRes 422 HQ master, H.264 delivery, the freeze loop, every view, timeline.json for your NLE, the cost ledger and the exact graphs that ran.

free

One container for the team

Docker or Fly.io (Frankfurt config included). No GPU on the host: generation never touches it.

Shared key and password

A server-side Comfy Cloud key so nobody pastes one, and an app password on every API call.

Guard rails and a ledger

Jobs in flight are capped, transient Comfy Cloud errors retry with backoff, and every paid job is booked against your balance.

Honest limitations

  • Qwen invents what the phone never saw, like the back of your head. Back views are the weakest, so orbit-* and sweep stay in front of you.
  • LTX can let a frozen person drift slightly (a blink, hair moving). Re-roll the orbit, or describe the person in Who is frozen?
  • One person, one take, up to 30 s. Output is upscaled from 704x1280.

Use it kindly

  • Only use your own face, or the face of someone who agreed.
  • Don't post it where it could pass as real footage of an event.
  • Code is MIT. The models keep their own licenses.
