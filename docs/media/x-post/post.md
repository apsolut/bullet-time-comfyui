# Bullet Time: X post kit

## Files
- bullet_time_x_4x5.mp4: main post video (17 s, 1080x1350, with sound). Best for the X feed on phone and desktop.
- bullet_time_x_9x16.mp4: same edit, full vertical, if you also post to Reels, Shorts or TikTok.
- bullet_time_x_collage.jpg: 2x2 still (real frame + 3 orbit angles). Use as a reply image or a second post, not instead of the video.
- bullet_time_x_poster.jpg: the FREEZE frame, if you need a thumbnail.

## How to post
1. Upload the 4:5 video natively (do not post a YouTube link, X buries those).
2. Put links in the main post only once; X shortens every link to 23 characters.
3. Reply to your own post with the collage + GitHub link, so the main post stays clean.
4. Best time: weekday morning US time (15:00 to 17:00 Germany).

## Variant A (recommended)
I froze one moment of a selfie video and flew the camera around myself.

One phone clip in, a full bullet time orbit out. Built on @ComfyUI with @ltx_io LTX-2.5, all open weights.

Try it free: https://bulletcam.apsolut.dev

Open weights, runs on @ComfyUI. Made with @ltx_io LTX-2.5.

Free to try: https://bulletcam.apsolut.dev

## Variant C (builder angle, mentions the challenge)
Built for the Open Source Higgsfield challenge: a bullet time app on @ComfyUI.

Qwen Image Edit makes the angles, @ltx_io LTX-2.5 flies the orbit, ffmpeg stitches it back into your clip.

Code: https://github.com/apsolut/bullet-time-comfyui
Try: https://bulletcam.apsolut.dev
